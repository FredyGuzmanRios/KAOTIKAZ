Seis variantes

Las seis comparten el mismo aparato, el mismo flujo de compra (teclado, transferencia con datos copiables, comprobante y folio) y ya llevan el logotipo oficial en vez del texto. A, B y D son la misma maquina con el ticket vivo al lado — en movil ese ticket aparece hasta que se completa el pago —; C es solo el aparato. La seccion de fases se cambio por un banner de fase en vivo. Todas suman, arriba, el manifiesto de bienvenida con dos botones (Ver artistas / Comprar boletos) y un carrusel deslizable para las tarjetas de artistas, que ahora es el unico modo de vista (ya no se puede cambiar a cuadricula) y funciona igual en movil, con tarjetas mas angostas para que se note que hay mas para deslizar.
